ТРЕНУВАЛЬНИЙ ЖУРНАЛ — веб-програма для Telegram і телефона
=============================================================

У папці:
  index.html              — сама програма
  manifest.webmanifest    — щоб її можна було встановити на телефон як застосунок
  sw.js                   — щоб відкривалася без інтернету після першого запуску
  icon-*.png, apple-touch-icon.png — іконки

Telegram вимагає, щоб програма була на сайті з адресою https://.
Тому спершу розмістіть цю папку на безкоштовному хостингу.


КРОК 1. Розмістити папку в інтернеті (5 хвилин, безкоштовно)
-------------------------------------------------------------
Варіант А — Netlify (найпростіше, перетягуванням):
  1. Відкрийте https://app.netlify.com/drop і зареєструйтеся (можна через Google).
  2. Перетягніть ЦЮ ПАПКУ (розпаковану) у вікно браузера.
  3. Netlify дасть адресу вигляду https://назва-123.netlify.app — це ваша програма.
     У налаштуваннях сайту (Site configuration → Change site name) можна змінити назву.

Варіант Б — GitHub Pages:
  1. Створіть акаунт на github.com і новий публічний репозиторій.
  2. Add file → Upload files → завантажте всі файли з папки → Commit.
  3. Settings → Pages → Branch: main, папка / (root) → Save.
  4. Через 1–2 хвилини адреса буде https://ваш-логін.github.io/назва-репозиторію/

Перевірте: адреса має відкриватися в браузері телефона.


КРОК 2. Створити бота в Telegram
--------------------------------
  1. Відкрийте в Telegram @BotFather і надішліть /newbot.
  2. Вкажіть назву (наприклад «Мій тренер») і ім’я бота, яке закінчується на bot.


КРОК 3. Прикріпити програму до бота
-----------------------------------
Кнопка в меню бота:
  1. У @BotFather: /mybots → ваш бот → Bot Settings → Menu Button.
  2. Надішліть адресу з кроку 1 (https://...) і назву кнопки, наприклад «Тренування».
  3. Тепер у чаті з ботом біля поля введення буде кнопка, що відкриває програму.

Пряме посилання на програму (за бажанням):
  1. У @BotFather: /mybots → ваш бот → Bot Settings → Configure Mini App → Enable Mini App,
     вкажіть ту саму адресу.
  2. Посилання для відкриття: https://t.me/ІМ’Я_БОТА?startapp
     Його можна надіслати клієнтам — програма відкриється одразу в Telegram.


ДЕ ЗБЕРІГАЮТЬСЯ ДАНІ
--------------------
  • У Telegram — у хмарі Telegram окремо для кожного користувача.
    Ви з телефона й комп’ютера бачите свої записи, кожен клієнт — лише свої.
    Ліміт Telegram: 1024 записи на людину, цього вистачить на кілька років тренувань.
  • У звичайному браузері — лише на цьому пристрої.

Перенести дані (наприклад, з версії в Claude у Telegram):
  Профіль → «Перенесення даних між пристроями» → «Скопіювати всі дані»,
  потім у іншій версії встав текст у поле й натисни «Імпортувати».


ВСТАНОВИТИ НА ТЕЛЕФОН ЯК ЗАСТОСУНОК (без Telegram)
--------------------------------------------------
  Android (Chrome): відкрийте адресу → меню ⋮ → «Додати на головний екран» / «Встановити».
  iPhone (Safari):  відкрийте адресу → «Поділитися» → «На екран „Додому“».


ОНОВЛЕННЯ
---------
Коли отримаєте нову версію index.html — завантажте її на той самий хостинг
(у Netlify: Deploys → перетягнути папку ще раз). Посилання й кнопка в боті не зміняться,
дані користувачів збережуться.
